# FindIt — Application Screenshots & UI Showcase

This directory stores visual previews and screenshots of the FindIt application for documentation and portfolio presentation.

### Showcase Checkpoints:
- `landing-page.png`: Public responsive hero section, features, stats, and workflow.
- `browse-items.png`: Search, multi-category filters, status pills, and responsive item grid.
- `report-item.png`: Comprehensive reporting form with instant local image preview.
- `item-details.png`: Detailed item report breakdown and ownership claim flow.
- `dashboard.png`: Analytics overview, quick actions, and recent activity.
- `ai-matches.png`: Prototype semantic match breakdown with similarity indicators.
- `admin-dashboard.png`: Moderation statistics, item and user management table.
